# Implementation

In-flight, staged work: what version is current, what's done, what's next,
and in what order. This is the only directory expected to change release to
release — update it as scope moves from "proposed" to "done." Once an idea
here is fully shipped and stable, its lasting description belongs in
[`../foundation/`](../foundation/INDEX.md), not here.

| Doc | What's in it |
|---|---|
| [`ROADMAP.md`](ROADMAP.md) | Current version status, done/known-gaps, next release's proposed order, explicitly out-of-scope items |

See also: [`../foundation/INDEX.md`](../foundation/INDEX.md) for what's
permanent, and [`../proposal/INDEX.md`](../proposal/INDEX.md) for ideas not
yet scheduled into a release.

# Proposal

Things under consideration: ideas that have been discussed and deliberately
deferred, but aren't committed to any version and aren't being built yet.
Nothing in this directory is a spec. When a proposal is scheduled for actual
work, move its plan into [`../implementation/`](../implementation/INDEX.md)
rather than editing it in place here.

| Doc | What's in it |
|---|---|
| [`FUTURE_IDEAS.md`](FUTURE_IDEAS.md) | Unscheduled ideas (e.g. v2 LAN sync / "iTunes for novels") |

See also: [`../foundation/INDEX.md`](../foundation/INDEX.md) for what's
actually built and stable, and [`../implementation/INDEX.md`](../implementation/INDEX.md)
for in-flight staged work.

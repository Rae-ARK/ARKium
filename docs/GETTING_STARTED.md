# Getting Started

## Prerequisites
- Node.js (LTS)
- npm
- Neutralino CLI: `npm install -g @neutralinojs/neu`

## Install dependencies
```bash
npm install
```

## Run in development
```bash
npm run dev
```

## Neutralino runtime
```bash
neu update       # fetch/update native Neutralino binaries
neu run          # launch the app shell
```

## Build
```bash
npm run build     # builds the Vue frontend
neu build          # packages the native app
```

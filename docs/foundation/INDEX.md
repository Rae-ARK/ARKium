# Foundation

Permanent, stable information about ARKium: what it is, how it's built, and
how it relates to its Android siblings. These documents describe things as
they actually are (or how to get the project running), not things under
discussion. If something here goes stale, fix it in place rather than
proposing a replacement.

| Doc | What's in it |
|---|---|
| [`ARCHITECTURE.md`](ARCHITECTURE.md) | Stack, code layout, design decisions and rationale, relationship to ARKster/ARKarium |
| [`ANDROID_REFERENCE.md`](ANDROID_REFERENCE.md) | Snapshot of the two Android sibling codebases, for deliberate (not accidental) parity |
| [`UI_SCREENS.md`](UI_SCREENS.md) | Long-term target screen specifications (Home, Fiction, Chapter) |
| [`GETTING_STARTED.md`](GETTING_STARTED.md) | Prerequisites, build, run, install |

See also: [`../proposal/INDEX.md`](../proposal/INDEX.md) for ideas under
consideration, and [`../implementation/INDEX.md`](../implementation/INDEX.md)
for what's actually being staged and built right now.
